# ⚙️ Engenharia de Software

Repositório de estudos da disciplina **Engenharia de Software** — processos de desenvolvimento, levantamento de requisitos, modelagem, projeto, implementação, testes e manutenção de sistemas.

## 📖 Sobre a disciplina

Compreensão de como softwares são planejados, desenvolvidos, validados e mantidos de forma organizada, utilizando processos, técnicas e boas práticas da engenharia.

## 🎯 Objetivo

Compreender como softwares são planejados, desenvolvidos, validados e mantidos, utilizando processos, técnicas e boas práticas de engenharia.

## 📚 Conteúdo estudado

| Bloco                                   | Tópicos                                                                           |
| --------------------------------------- | --------------------------------------------------------------------------------- |
| **Introdução à Engenharia de Software** | Conceito de software · crise do software · engenharia de software como disciplina |
| **Processos de software**               | Modelo cascata · modelo incremental · prototipação · espiral                      |
| **Engenharia de requisitos**            | Elicitação · análise · especificação · validação                                  |
| **Modelagem de sistemas**               | Diagrama de casos de uso · diagrama de classes · modelagem UML                    |
| **Projeto de software**                 | Arquitetura de software · modularização · separação de responsabilidades          |
| **Implementação**                       | Codificação · padrões de desenvolvimento · versionamento                          |
| **Testes de software**                  | Testes unitários · testes de integração · testes funcionais                       |
| **Manutenção de software**              | Correções · adaptações · evolução do sistema                                      |
| **Gerência de configuração**            | Controle de versões · Git · GitHub                                                |
