## 📖 Sobre a disciplina

A disciplina cobre todo o ciclo de vida de sistemas de Machine Learning voltados a hardware embarcado e edge computing — desde os fundamentos de algoritmos e infraestrutura de dados até a implantação de modelos generativos multimodais rodando localmente em dispositivos como Raspberry Pi. Os laboratórios são práticos por natureza, progredindo de configurações básicas de hardware até sistemas integrados complexos com múltiplos modelos.

## 🎯 Objetivos

Projetar, implementar e operar sistemas de ML em todo o espectro entre computação embarcada e edge computing, com ênfase particular em ambientes com recursos restritos.

## 📚 Conteúdo programático

| Semanas | Módulo                                    | Tópicos                                                                                                                                                                                                                                                 |
| ------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1-2     | **Fundamentos de ML Systems Engineering** | Fundamentos de sistemas de ML (algoritmos, dados, infraestrutura de computação) · Conceitos e arquiteturas de edge computing · Setup de hardware (Raspberry Pi 5 e Pi Zero 2W) · Configuração do ambiente de desenvolvimento · Python essencial para ML |
| 3-4     | **Computer Vision Systems**               | Arquiteturas CNN e otimização · Classificação de imagens com MobileNet · Detecção de objetos com YOLOv8 · Processamento em tempo real com câmeras USB/CSI · Técnicas de otimização de performance                                                       |
| 5-6     | **Model Customization e Edge ML**         | Fundamentos de transfer learning · Plataforma Edge Impulse · Coleta e anotação de dataset · Implementação de FOMO (Faster Objects, More Objects) · Otimização de modelos para deployment em edge                                                        |
| 7-8     | **Arquiteturas Avançadas de ML**          | RNNs para dados sequenciais · Transformers para visão computacional · Implementações de Vision Transformer (ViT) · Comparação entre CNNs e Transformers em edge · Arquiteturas eficientes em recursos                                                   |
| 9-10    | **GenAI em Edge**                         | Introdução a GenAI viável em edge · Setup e deployment do Ollama · Sistemas de image captioning · Function calling e integração com APIs · RAG (Retrieval-Augmented Generation)                                                                         |
| 11-12   | **CV Avançada com GenAI**                 | Vision Language Models (VLM): Microsoft Florence 2 e PaliGemma · Técnicas de fine-tuning                                                                                                                                                                |
| 13-14   | **Integração de Sistemas e Deployment**   | Design de sistemas multi-modelo · MLOps para dispositivos edge · Monitoramento e otimização de performance · Implementação do projeto final · Considerações de deployment em produção                                                                   |
| 15      | **Apresentação do Projeto em Grupo**      | Apresentação final dos projetos desenvolvidos ao longo da disciplina                                                                                                                                                                                    |

> 💡 Os laboratórios têm foco prático, usando hardware Raspberry Pi, progredindo de setups básicos até sistemas integrados complexos.
