# 📘 Discrete Math Toolkit - C Edition

Projeto desenvolvido em **Linguagem C** como aplicação prática dos principais conceitos estudados na disciplina de Matemática Discreta.

O sistema reúne operações matemáticas fundamentais em um ambiente modular, permitindo trabalhar com conjuntos, relações, lógica proposicional e grafos, além de registrar operações realizadas durante a execução.

---

# 🚀 Objetivo do Projeto

Aplicar conceitos teóricos de Matemática Discreta através da implementação de algoritmos utilizando a linguagem C.

O projeto foi desenvolvido para consolidar conhecimentos em:

- programação estruturada
- modularização
- manipulação de arquivos
- estruturas de dados
- lógica computacional
- implementação de algoritmos matemáticos

