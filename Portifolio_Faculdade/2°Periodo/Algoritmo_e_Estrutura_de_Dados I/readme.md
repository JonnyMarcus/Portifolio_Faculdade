## 📖 Sobre a disciplina

A disciplina desenvolve a capacidade de entender conceitos teóricos e práticos associados a algoritmos e estruturas de dados básicos, aplicados ao desenvolvimento de programas de computador usando recursos de modularização e abstração de dados. Os conceitos são introduzidos através de uma linguagem de programação estruturada.

## 🎯 Objetivos

**Geral:** desenvolver a capacidade de entender conceitos, de cunho teórico e prático, associados a algoritmos e estruturas de dados básicos para o desenvolvimento de programas de computador, utilizando modularização e abstração de dados.

**Específicos:**
- Explorar conceitos, técnicas de implementação e aplicações das estruturas de dados mais utilizadas
- Capacitar o aluno a analisar e aplicar corretamente as estruturas de dados em problemas resolvidos computacionalmente
- Efetuar análises simples da complexidade de algoritmos
