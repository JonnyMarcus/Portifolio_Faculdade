## 📖 Sobre

O **EcoItamambuca** é uma plataforma web que utiliza **programação, geotecnologias e análise de dados** para registrar e visualizar problemas socioambientais no território de Itamambuca.

O sistema permite registrar ocorrências como **alagamentos, erosão, descarte irregular de resíduos e degradação ambiental**, associando cada registro à sua localização.

Os dados são apresentados em um **mapa interativo** e em um **dashboard**, permitindo identificar áreas com maior concentração de problemas e apoiar propostas de **Soluções Baseadas na Natureza (SbN)**.

---

## 🎯 Objetivos

- Monitorar problemas socioambientais;
- Georreferenciar ocorrências;
- Organizar dados territoriais;
- Identificar áreas prioritárias;
- Auxiliar no planejamento ambiental;
- Aplicar programação em um problema real.

---

## 🗺️ Funcionalidades

- 📍 Cadastro de ocorrências;
- 🗺️ Mapa interativo;
- 📊 Dashboard de indicadores;
- 🔎 Filtros por categoria e severidade;
- ⚠️ Classificação de prioridade;
- 🌱 Sugestão de Soluções Baseadas na Natureza;
- 🛰️ Integração com dados do QGIS.
